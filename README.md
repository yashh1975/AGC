# Anjaneya Gold Company (AGC)

A premium, modern digital platform for **Anjaneya Gold Company** — Bengaluru's trusted gold services company with 20+ years of experience.

🌐 **Live Website**: [https://anjaneyagoldcompany.com](https://anjaneyagoldcompany.com)

## 🌟 Features

- **Cinematic Visual Experience**: 3D gold ornament transformations, orbital animations, and ambient particle effects.
- **Core Services**:
  - 🪙 **Sell Gold for Cash**: Transparent valuation based on live market rates.
  - 🔓 **Release Pledged Gold**: Quick settlement with banks & financiers.
  - 🔄 **Re-Pledge Gold**: Better terms and financial flexibility.
  - 🚗 **Mobile Gold Service**: Doorstep gold evaluation and instant transaction.
- **German XRF Testing**: Precision non-destructive 99% purity analysis.
- **High Performance**: Optimized for 120 FPS scrolling across mobile (iOS/Android) and desktop.
- **Direct WhatsApp & Phone Integration**: Instant contact and branch directions.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Animations**: GSAP (ScrollTrigger), Framer Motion, HTML5 Canvas Particles
- **Icons**: Lucide React
- **Deployment**: Cloudflare Pages

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation & Local Development

```bash
# 1. Clone the repository
git clone https://github.com/yashh1975/AGC.git

# 2. Navigate to project directory
cd AGC

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

The application will be running locally at `http://localhost:5173`.

### Production Build

```bash
# Build production bundle to /dist
npm run build

# Preview production build locally
npm run preview
```
